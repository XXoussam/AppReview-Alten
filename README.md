# Clip review app

Web app to upload a game video, cut it into timestamped clips, and review transcripts, speakers and
PAD scores. Split out of `Esports-Event-to-Commentary-Generation-LoL` (commit `5080ce5`).

Full documentation: [review_app/README.md](review_app/README.md). Run every command from this folder;
the app keeps its database, users and files in `review_data/` here (override with `REVIEW_DATA_DIR`).
